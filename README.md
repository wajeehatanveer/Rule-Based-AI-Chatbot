# 🤖 Rule-Based AI Chatbot

A simple Rule-Based AI Chatbot built using Python. This chatbot responds to predefined user inputs using if-elif-else statements and runs continuously until the user exits.

 # Features

- Greeting responses (Hi, Hello, Hey)
- Answers common questions
- AI and Python information
- Help command
- Good Morning / Good Night greetings
- Thank You response
- Exit commands (bye, exit, quit)
- Default response for unknown input

## Technologies Used

- Python 3

## Concepts Used

- if-elif-else
- while loop
- input() and print()
- String methods (`lower()` and `strip()`)

## How to Run

1. Install Python.
2. Open a terminal in the project folder.
3. Run:

```bash
python Chatbot.py
```
